Three-Hour Class Block

SegmentMinutesRequired Elements
Student Check-In10Attendance, PPE inspection, tool accountability, bench assignment.
Safety Brief10PPE, today's hazards, fire safety, battery safety, electrical safety, meter inspection, tool inspection, emergency procedures.
Lesson Review15Prior lesson review, vocabulary, CETa objective connection.
New Instruction35Core concept, examples, board work, student questions.
Instructor Demonstration10Demonstrate the lab task, tool use, safety boundary, and documentation expectation.
Hands-On Lab75Student practice, measurement logs, repair tickets, instructor coaching.
Practical Checkoff10Observable performance check or progress signoff.
Laboratory Shutdown10Power off, disconnect, de-energize, return tools/components/PPE, clean workstation.
After Action Review5Mission, results, successes, problems, safety, improvements, questions.

Usage Requirement

Each week and daily lesson page should reference this framework so the course runs as a consistent workforce training program rather than a collection of unrelated lessons.
